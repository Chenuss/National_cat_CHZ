# National Catalog API Client

Python-клиент для работы с API Национального Каталога маркированных товаров (Честный Знак).

## Описание

Проект предназначен для получения данных о товарах из Национального Каталога через API и сохранения их в локальную базу данных SQLite.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` и добавьте ваш API ключ:
```
API_KEY=ваш_api_ключ
```

## Использование

Запустите скрипт для получения списка товаров:
```bash
python catalog_client.py
```

## Структура проекта

- `catalog_client.py` - основной скрипт клиента
- `catalog.db` - база данных SQLite (создаётся автоматически)
- `.env` - файл с конфигурацией (API ключ)
- `requirements.txt` - зависимости Python
- `PRD.md` - документ с требованиями к продукту
- `README.md` - этот файл

## API Endpoint

Используется endpoint `/v4/product-list` Национального Каталога:
- Продуктивная среда: `https://апи.национальный-каталог.рф/v4/product-list`
- Тестовая среда: `https://api.nk.sandbox.crptech.ru/v4/product-list`

## Параметры запроса

- `from_date` - Дата начала периода (YYYY-MM-DD HH:MM:SS)
- `to_date` - Дата окончания периода (YYYY-MM-DD HH:MM:SS)
- `limit` - Количество записей (максимум 1000)
- `good_status` - Статус карточки товара
- `apikey` - Ключ доступа API

## Полученные данные

Скрипт получает следующие поля для каждого товара:
- `good_id` - Идентификатор карточки в системе Честный Знак
- `gtin` - Global Trade Item Number (GS1 Rus)
- `good_name` - Торговое наименование товара
- `tnved` - Код ТНВЭД
- `brand_name` - Торговая марка
- `good_status` - Технологический статус
- `good_detailed_status` - Массив детальных статусов
- `updated_date` - Дата обновления статуса
