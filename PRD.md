# National Catalog API Client - Product Requirements Document

## Overview
Проект представляет собой Python-клиент для работы с API Национального Каталога маркированных товаров (Честный Знак). 

## Цель
Автоматизация получения данных о товарах из Национального Каталога и сохранение их в локальную базу данных SQLite.

## Функциональные требования

### Этап 1: Получение списка товаров
- Выполнение GET-запроса к endpoint `/v4/product-list` API Национального Каталога
- Параметры запроса:
  - `from_date`: Дата начала периода (формат: YYYY-MM-DD HH:MM:SS)
  - `to_date`: Дата окончания периода (формат: YYYY-MM-DD HH:MM:SS)
  - `limit`: Количество записей за один запрос (максимум 1000)
  - `good_status`: Статус карточки товара (например, `published`)
  - `apikey`: Ключ доступа API

- Сохранение полученных данных в SQLite базу данных `catalog.db`

### Структура данных товара
| Поле | Тип | Описание |
|------|-----|----------|
| good_id | integer | Идентификатор карточки в системе Честный Знак |
| gtin | string | Global Trade Item Number в системе GS1 Rus |
| good_name | string | Торговое наименование товара |
| tnved | string | Товарная номенклатура ВЭД ЕАЭС |
| brand_name | string | Торговая марка |
| good_status | string | Технологический статус карточки товара |
| good_detailed_status | array | Массив текущих статусов карточки товара |
| updated_date | string | Дата обновления технологического статуса |

## Технические требования

### Зависимости
- Python 3.8+
- requests (HTTP-запросы)
- python-dotenv (управление переменными окружения)

### Конфигурация
- API ключ хранится в файле `.env`
- URL API берётся из документации (продуктивная или тестовая среда)

### База данных
- SQLite в файле `catalog.db`
- Таблица `products` с полями, соответствующими структуре данных товара

## Нефункциональные требования
- Обработка ошибок API
- Логирование основных событий
- Соблюдение лимитов запросов к API (500 запросов за 5 минут)

## Будущие расширения
- Пагинация при получении большого количества товаров
- Обновление существующих записей
- Полная синхронизация с API
- Расширенная фильтрация по параметрам
